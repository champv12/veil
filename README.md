# Veil Core

Veil Core is the open-source, local-first engine behind Veil's Logical Change,
Recovery Anchor, evidence, evaluator, agent-runner, and Git adapter modules.
It is MIT licensed and accepts community contributions.

This repository contains local Core libraries only. Veil Cloud is optional and
maintained separately. Official signed installers and marketplace artifacts are
published from the distribution-only `champv12/veil-releases` repository.

## Develop

Requires Node 24.

```sh
npm ci
npm run build
npm test
```

Read [CONTRIBUTING.md](CONTRIBUTING.md) before opening a pull request.
