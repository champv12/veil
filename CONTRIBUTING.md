# Contributing

Thank you for helping improve Veil Core.

1. Open an issue for large behavior or contract changes.
2. Fork the repository and create a focused branch.
3. Add or update tests, then run `npm run build && npm test`.
4. Open a pull request explaining the behavior change and privacy impact.
5. Sign off every commit with `git commit -s` to certify the DCO.

Contributions are licensed under the same MIT license as the project. Never
include credentials, private repositories, customer data, internal runbooks, or
generated release artifacts. Report security issues privately as described in
[SECURITY.md](SECURITY.md).
